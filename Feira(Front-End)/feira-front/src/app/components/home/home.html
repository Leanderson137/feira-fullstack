Sistema Feira

Sistema para gerenciamento de feirantes e categorias. Cadastre, edite, liste e organize informações da feira de forma simples e intuitiva.

👨‍🌾

Feirantes

Gerencie os feirantes cadastrados no sistema, incluindo cadastro, edição e exclusão.

🗂️

Categorias

Organize as categorias utilizadas pelos feirantes para facilitar o gerenciamento da feira.

Projeto desenvolvido com Angular.
